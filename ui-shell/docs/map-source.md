# Canvas atlas source and rendering

The coastlines use [Natural Earth 1:110m physical land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson), downloaded on 2026-10-01. [Natural Earth's terms](https://www.naturalearthdata.com/about/terms-of-use/) place all of its vector and raster data in the public domain.

`public/map/land-polygons.json` contains 53 intersecting land rings with 2,560 vertices. Features that do not intersect the atlas's broad geographic extent (25°W–155°E, 25°S–80°N) were discarded, attributes were removed, and coordinates were rounded to three decimals. This reduces the local file to about 42 KB. It is loaded on map mount; no remote service is used at runtime. The map's projection is an intentionally simple equirectangular projection with a fixed 1.18 vertical stretch.

All styling, mountains, desert etching, compass, city symbols, labels, and decorative routes are original procedural Canvas drawing. River paths and territory shapes are manually drawn, illustrative approximations. Coastlines represent modern general geography; this is a fictional UI prototype, not a historical reconstruction. No Crusader Kings artwork, maps, icons, fonts, or layout assets are used.

The atlas has one visible Canvas and one detached base-layer cache. Both use a maximum device pixel ratio of 1.5 and a pixel budget of 2.4 million pixels per surface. Procedural water, mountains, desert marks, rivers and grid are precompiled into seven reusable `Path2D` groups, with a cached paper pattern; repainting does not rebuild individual shapes. A viewport change invalidates the cached geography; civilization/time/layer/selection changes reuse that cache. Redraws are scheduled only when dirty. Cities and capital markers are culled to the viewport before drawing and hit-testing. City labels avoid all civilization emblems and their name/subtitle bounds; crowded names are relocated or omitted while city markers remain available. Pointer hover does not invalidate the map. ResizeObserver, pointer events, keyboard navigation, and event-based repainting avoid a permanent animation loop.

The parent application supplies civilization snapshots for a year. The map does not simulate history or mutate that data. `focusId` and `focusToken` offer a deliberate recenter action independent of selection. An optional `focusPosition` locates a specific city and highlights its marker. The `onStats` callback exposes draw duration, cumulative draws, visible/total markers, and Canvas pixel count. These measurements are also available as passive `data-*` attributes on the visible Canvas, alongside zoom, geographic center and visible civilization marker positions for browser verification. Measurements describe the drawing call on this device, not guaranteed frame rates across hardware. Initial fitting reserves room for the map heading and bottom event shelf; explicit focus actions center civilizations in the exposed map area.
