## 起局设置和关键证据

- A/B/D/E/H：AI 克制，数值模式，发源地 `cb05`。A/D/H 用杨卫平，B/E 用克莱尔。发展科学或神学，并维护财政、人口、秩序与 EERF；D/E/H 的候选结局通过正常“脱离苦海”行动结算。
- F/G：AI 标准，杨卫平，数值模式，发源地 `cb05`。F 走均衡发展与 EERF，G 走真实灾变与重启循环，出现对应候选后正常结算。
- C/I/J：AI 克制，拉特尔，数值模式，发源地 `cb05`。C 的 18 代科学峰值均低于 1,600；I 第 17–31 代末次秩序均低于 20，第 32 代秩序降至 16 时自动结束；J 第 55–57 代 LA 峰值为 20,000 / 18,561 / 18,511，最后一代达到门槛时自动结束。逐代证据在运行时收集，因此不受存档只保留最近 12 代的上限影响。
- K：AI 克制，杨卫平，领土模式全程开启，发源地 `cb05`。征兵、整训与实际远征，灾后正常重启继承领土；最终所有 64 省归属本国，军力 50,125，正常结算。
- L：AI 全面战争，监听员，领土模式全程开启，发源地 `nb01`。使用道路连接的真实部署过度出击并忽视补军；敌国攻陷最后一省后自动结束，0 省、0 本国军团，最后军情为战败。灾变期间临时清空的地图不作为灭国证据。

## 复跑

在仓库根目录运行：

```sh
npm run test:endings
```

各案例在独立 Node 进程中执行。测试输出到忽略的 `ui-shell/test-results/ending-reachability.json`，包含起局配置、全部合法命令、逐代/军事证据、真实终局存档和实际持久化内容。

开启生产预览后，可验证全部结局页：

```sh
npm run ui:preview -- --port 4173
# 在另一终端运行：
npm --prefix ui-shell run test:endings:browser
```

浏览器检查读取上一步实际生成的终局记录，使用隔离上下文，检查各结局原文与引用、最终/峰值指标、刷新恢复、返回只读世界与再次进入。日常浏览器的存档不会被测试替换。

| 文件 | 用途 |
| --- | --- |
| `scripts/test-ending-reachability.mjs` | 12 种结局的统一新局、重放与恢复检查 |
| `scripts/lib/ending-reachability-harness.mjs` | 真实公开引擎接口与合法命令录制 |
| `scripts/ending-routes-knowledge.mjs` | A/B/D/E/H 的发展策略 |
| `scripts/ending-routes-cycle.mjs` | F/G 的均衡与文明循环策略 |
| `scripts/ending-routes-hidden.mjs` | C/I/J 的跨代策略及逐代证据 |
| `scripts/ending-routes-military.mjs` | K/L 的真实战争路径 |
| `ui-shell/scripts/check-ending-browser.mjs` | 全部终局的网页恢复与展示检查 |
