# 文明摇篮 / Cradles Of Civilization

一个受“三颗恒星文明循环”启发的原创文字策略小游戏。

原创企划 / Original concept: Noah Walker.

当前开发主线：`v0.4.0-alpha.6`（HTML，中英双语，包含地图与军事）

分支分工：`master` 用于 HTML 游戏开发、测试和打包；[`godot-port`](https://github.com/Tech-Echo-Collective/cradles-of-civilization/tree/godot-port) 保留 Godot 原生移植工程。后续网页修改提交到 `master`。

在线试玩：[techecho.org/games/cradles-of-civilization/](https://techecho.org/games/cradles-of-civilization/)

官网使用 [`Tech-Echo-Website` 中的网页副本](https://github.com/Tech-Echo-Collective/Tech-Echo-Website/tree/main/public/games/cradles-of-civilization)，发布官网时需另行同步；本仓库 `master` 是 HTML 源码主线。

正式 HTML 已接入 CK3-lite 地图视图：固定三体大陆、64 个省份、10 个战略区和 167 条合法邻接，支持政治/地形/军事三种图层、拖动缩放，以及可切换的轻微斜视纯 SVG 立体地形。选择军队与相邻省份后，仍在右侧地块面板下达防御或进攻命令；年份、征兵、战斗、AI、战争迷雾与存档全部沿用正式游戏规则，不存在第二套回合。

独立地图实验室仍位于 `map-lab/`，用于试验更直接的移动、战斗、伤亡、占领、撤退与征兵交互；它不读写正式存档。

Godot 原生试玩版在 `godot-port` 分支保留为 `v0.4.0-alpha.3`（中英双语，暂不含地图与军事），当前暂停打包。

无地图内容与文案基准：`v0.2`（最后一个尚未加入地图/军事的正式版本）

## 运行

网页版可直接用浏览器打开 `index.html`，右上角可切换中文/English；`?lang=en` 可直接打开英文版。

正式游戏的地图在完成建国后直接显示。地图实验室可另行打开 `map-lab/index.html`；也可以用本地静态服务器访问 `/map-lab/`。

## 打包分享

`npm run package` 生成当前 HTML 版 ZIP，并包含中英双语运行文件；网页版存档保存在各自浏览器本机，不会跟着 ZIP 传播。

Godot 的运行和原生导出说明见 [`godot-port` 分支的 README](https://github.com/Tech-Echo-Collective/cradles-of-civilization/blob/godot-port/godot/README.md)。

## 基础规则

- `SC` 是科学，`BE` 是神学，二者上限都是 `20000`。
- `SC/BE` 各自有趋势值，代表下一年会自然兑现的知识增产量；趋势由上一年趋势、经济、人口、秩序、路线压制、行动和事件共同决定。
- `POP` 是人口，没有硬上限，但人口过高会引发额外风险。自然人口变化围绕文明承载力形成 S 型曲线，科技、神学、经济和秩序只提供小幅修正。
- `ECO` 是经济资本，会被事件、行动成本和部分彩蛋影响；低位经济会出现少量社会自救缓冲，但财政仍可能归零。
- `LA` 是文学艺术，最高为 `20000`；它主要作为 EERF 的线性保存增幅，满值时可让灾后保存达到毁灭轮 `SC/BE` 的约一半、正向趋势的八成。
- `POP/ECO/LA/秩序` 也会显示趋势值，但这些趋势只记录最近一年真实变化，不额外改变底层演化模型。
- v0.3.5 曾使用 `25` 个随机区域；当前正式游戏已迁移到固定的 `64` 省大陆和 `167` 条邻接关系。seed 只重排五方连通疆域，玩家选择的省份始终成为首都。旧存档会保留文明数值、EERF 和编年史，并一次性重建战略版图与驻军。
- 世界包含玩家国、两个中立政权和两个敌对政权。每个政治实体都有独立的领土、军力、发展、技术与国家策略面板；AI 会根据和平、战争、领土和技术情况自行调整策略，玩家可随时选择自己的策略。
- 开始新世界时先命名国度，再选择简单、普通、困难或终极困难，并单独设置克制、标准、好战或全面战争四档 AI 侵略性；难度调整敌军与中立军基础强度，侵略性调整出兵频率、玩家目标偏好和攻击加成。
- 点击可见军队可查看其兵力、进攻、防守和驻地。玩家军团每年可部署一次，点击部署后立即结算：进入己方地区视为防守，进入中立或敌方地区视为进攻；攻击中立国家会使该政治实体整体转为敌对。
- 每类地形都有独立攻防修正。两军伤亡率由攻击与防御差值、接战强度和科技时代差决定；科技至少领先一个时代时，阵亡率限制在 `5%-95%`。战后败军撤回相邻领土，“远征”最多连续征服三块道路相连的领土并在首败后停止。
- 在已有本国军队的领土上征兵会自动合并兵力；在空领土上征兵会组建新的地方军团。军队全灭后仍可选择本国领土重建军团。
- 战争迷雾默认只显示本国领土和相邻领土的军事单位；三体监听员可以观察全图。国家名称通过地图裁切严格限制在本国疆域内。
- 军事系统包含军力、进攻、防守、整训、工事、边境攻防、灭国判断和全图征服判断。科技会提供封顶军事加成，国家策略继续修正攻防与征募；任何政治实体失去最后一块领土时都会灭亡，其全部军事单位立即解散。K 需要控制全图并维持 `18000` 军力，L 仅在失去全部地区时自动结算。
- 秩序按 `20` 分级：`0-20` 无政府、`20-40` 封建、`40-60` 君主立宪、`60-80` 资本主义、`80-100` 极权国家。
- `EERF` 是极端环境抵抗设施，建造和升级会消耗经济、科学、神学和人口，但能提高下一代文明初始人口，并保存下一代的 `SC/BE` 与正向趋势。
- EERF 第 `2/3/4/5` 级分别需要 `SC 2000/4000/8000/16000` 解锁。
- 新世界默认使用当前时间生成种子；首页命名栏下方可以手动输入数字种子或重新生成随机世界，结算页也保留种子入口。访问 `index.html?seed=1058` 会直接用指定种子开局。
- 同一年还会后台掷出隐藏 `SPEC`，范围为 `1-5000`，只在命中特殊事件时执行；特殊事件栏常驻显示，未命中特殊事件时显示“日光之下，并无新事。”
- 命中特殊事件时，屏幕会显示事件名、`SPEC` 数字、说明和本次变化。
- 普通随机事件和状态事件里的 `SC`/`BE` 基础单项变化被压到 `50` 以内；自然知识增长由趋势兑现，特殊事件和玩家行动可以超过。
- 行动收益被压低，文明需要长期积累才会跨越时代。
- 行动后会结算系统压力：SC/BE 会互相压制，接近均衡时压制减弱；POP 会按承载力 S 型增长或回落，ECO 使用简化的 Solow-Cobb-Douglas 经济模型结算，随后生成下一年的 SC/BE 趋势。
- 秩序作为组织 Buff 参与系统压力：神学会抬高秩序目标，秩序会提高科学年度增长，科学发展继续反向压制神学。
- 经济模型中，`ECO` 近似资本存量，`POP` 近似劳动力，二者共同产生年度产出并呈边际递减；`SC` 提高全要素生产率，`BE` 作为教义摩擦压低可投资产出。年度 `ECO` 变化约等于生产性投资减去折旧、人口维护、知识行政、EERF 维护与过载成本。
- `ECO` 为 `0` 时进入经济危机，除“重启财政”外的行动会锁死，所有正向 `SC`/`BE` 发展都会被冻结。
- “重启财政”的周转资金在本年维护与战事结算后到账，避免救济金立即被扣光；恢复当年仍冻结正向知识发展。若回合开始时财政正常、随后被事件扣至零，已选择的“刺激经济”或“均衡治理”仍可执行其收入效果，但不能绕过支出、人口与控制权限限制。
- “增强经济”可以提高 `ECO`，但会牺牲一部分人口、科学和神学推进。
- EERF 有 `0-5` 级，灾变时会保存火种人口、少量知识和极少量正向趋势，并在灾变后降级。高等级保存更多知识，`BE` 保存倍率约为同级 `SC` 的 `1.08` 倍。
- 建造或升级 EERF 需要保留最低可持续人口；如果人口成本会把本代文明扣穿底线，行动会被锁住。
- 如果建造或升级 EERF 的同一年掷中硬灾变，工程会先完成封门，再结算文明毁灭与火种保存。
- 世界事件和隐藏特殊事件先结算；如果文明没有毁灭，玩家选择的行动再结算。普通随机事件和普通隐藏事件不会把人口扣穿最低可持续人口，明确标记为穿透的事件除外。
- 部分 `Rand` 会直接触发毁灭一代文明的灾变，旧文明会等待玩家点击“重启文明”，再按 EERF 火种重新启动。
- 毁灭不是游戏终点。多数 `A-L` 结局条件满足后只会点亮“脱离苦海”，玩家可以继续发展，也可以手动结算；候选终局只属于当前这代文明，本代毁灭后即失效。国家灭亡会自动进入 `L`，全图征服会点亮 `K`。
- 自动结算只保留少数情况：单线 `SC` 抵达上限且 `BE` 未同步封顶时会自动结算 `A`，单线 `BE` 抵达上限且 `SC` 未同步封顶时会自动结算 `B`；双线同时封顶会转入双相判断。隐藏 `C` 只会在连续 `18` 代文明毁灭且最高 `SC` 都低于 `1600` 时自动结算；当低科学连败接近 `C` 时，普通废墟结局 `G` 会让位给隐藏判定。`I` 会在连续 `16` 代文明以无政府秩序收束时自动结算；`J` 会在连续 `3` 代文明都曾使 `LA` 达到 `18000` 时自动结算。
- “重启财政”和“重启文明”是两个不同选项：经济为 `0` 时重启财政，文明毁灭时重启文明。

## 终局统计

游戏不再提供跨局数值增益。每次抵达终局只会记录结局种类、总达成次数和最近一次终局，作为后续成就系统的基础。开始新世界不会清空终局统计；尚未触发过的结局会隐藏名称，显示为 `B-???` 这类格式。

## 时代

科学时代按 `SC` 划分：石器、铜石并用、青铜、铁器、古典机械、蒸汽、电气、原子、信息、太空、星际航行、宇宙工程、宇宙灯塔。

神学时代按 `BE` 划分：巫祝萌芽、图腾祭司、祖灵城邦、神权律法、经院神学、圣城体系、星火教会、宇宙神学、沉默圣殿、终末预言、唯一真言、归零信标、神圣闭环。

## 文明档案

每次文明毁灭时会封存一份档案，记录存续年数、峰值 `SC/BE/LA/POP/ECO`、灭亡原因和本代的重要特殊事件。

## 快捷键

每个按钮都会在界面上显示自己的快捷键。当前映射为：`S` 科学，`B` 神学，`P` 人口，`Shift+B` 均衡治理，`Z` 维持秩序，`1` 打压神学，`2` 打压科学，`H` 脱水，`L` 文学艺术，`E` 经济，`M` 发动远征，`V` 征兵，`X` 边疆戒严，`C` 强化王权，`G` 整训军团，`D` 构筑工事，`F` 建造 EERF，`U` 升级 EERF，`O` 重启财政，`R` 重启文明，`T` 脱离苦海，`Shift+L` 清空编年史，`Shift+N` 新世界。

## 平衡复算

运行 `npm run model` 会直接调用独立数学模型，输出地形胜率、双方伤亡率、领土边际收益和 J 连胜期望；它不加载前端。运行 `npm run balance -- 80 720 normal all standard` 可调用实际游戏引擎做抽样复核。运行 `npm test` 检查固定 64 省地理、五方连通分区、旧存档迁移、中英双语、伤亡边界、撤退、征兵合并、灭国清军和版图继承。

## 操作辅助

按钮锁定时会直接显示原因。主界面显示数值卡、卡内趋势、战略地图和军事状态；规则页已取消，终局观测、终局统计、EERF 保存预估和文明档案保留在文明系统侧栏。折线图在结局页通过“查看文明数据”打开。

## 结局

终局条件会检查 `SC`、`BE`、`LA`、`POP`、`ECO`、秩序、地图、军力、文明代际次数与毁灭情境。科学封顶、神学封顶、科学撤离、神学撤离、双相平衡、循环废墟、低智停滞、技术威权、罗马化崩盘、永志不忘、全图征服和国家灭亡都可能成为最终结局。除少数自动结算条件外，玩家需要点击“脱离苦海”才会真正进入结局页。

## 后台预留

v0.3 起特殊政策系统进入前台，首批包括征兵、边疆戒严和强化王权；政策拥有门槛、冷却、经济/人口/秩序代价和军事效果。

## 扩展事件

随机事件主要在 `game.js` 的 `specialEventFor`、`doomEvent`、`contextualEventFor` 和 `baseEvent` 中。

趋势升级或降级只会显示在特殊播报栏，不会写进编年史。

想加新的隐藏彩蛋，优先改 `specialEventFor(spec, rng)`。命中特殊事件时，`SPEC` 会显示在播报标题里。
